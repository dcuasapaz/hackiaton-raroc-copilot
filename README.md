## 📌 Project Overview

**SmartRAROC Copilot** is a real-time financial decision engine and conversational AI copilot built to solve one of banking's most persistent challenges: **understanding and optimizing client-level risk-adjusted profitability in real time.**

Traditionally, computing Risk-Adjusted Return on Capital (**RAROC**) across thousands of clients (*CIFs*) requires heavy, batch-processed financial models that run at month-end. This lack of immediacy leaves commercial advisors with no actionable insight during live client interactions.

This solution pairs a **deterministic financial computation engine** with an **Agentic Generative AI Copilot**. It instantly computes the true P&L breakdown, isolates cost drivers (such as high physical channel transaction costs), evaluates credit risk via **Expected Loss**, and prescribes immediate **Next Best Actions (NBA)** to transform loss-making clients into profitable relationships.

## 💡 Financial Foundations

The core engine implements a rigorous financial cascade aligned with international Basel standards and modern managerial accounting practices:

### 1. Risk-Adjusted Return on Capital (RAROC)
$$\text{RAROC (\%)} = \left( \frac{\text{Margen Operacional} - \text{Pérdida Esperada}}{\text{Capital Económico Requerido}} \right) \times 100$$

### 2. Cascading P&L Computation
* **Net Interest Income (NII):** 
  $$\text{NII} = (\text{Interés Ganado} - \text{Costo FTP Pasivo}) - (\text{Interés Pagado} - \text{Reconocimiento FTP Activo})$$
* **Operating Margin:**
  $$\text{Margen Operacional} = (\text{NII} + \text{Comisiones} + \text{Servicios}) - \text{Costos Operativos Totales}$$
* **Adjusted Margin (Risk-Adjusted):**
  $$\text{Margen Ajustado} = \text{Margen Operacional} - \text{Pérdida Esperada (EL)}$$

### 3. Key Financial Concepts
* **Funds Transfer Pricing (FTP):** Internal transfer pricing mechanism that isolates纯 financial margin from liquidity and interest rate risks.
* **Cost-to-Serve Optimization:** Uncovers hidden operational costs generated by high physical branch usage (ventanilla) vs. digital channel efficiency.
* **Expected Loss (EL) vs. Accounting Provisions:** Replaces static accounting provisions with forward-looking risk modeling:
  $$\text{EL} = \text{PD (Probability of Default)} \times \text{LGD (Loss Given Default)} \times \text{EAD (Exposure at Default)}$$

## 🚀 Installation & Setup

### Prerequisites
* Python 3.10 or higher
* `pip` and `venv`

### Step 1: Clone the Repository
```bash
git clone https://github.com/tu-usuario/hackiaton-raroc-copilot.git
cd hackiaton-raroc-copilot
```

### Step 2: Set Up Virtual Environment
```bash
# On Linux/macOS
python -m venv venv
source venv/bin/activate

# On Windows
python -m venv venv
venv\Scripts\activate
```

### Step 3: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 4: Configure Environment Variables
Create a `.env` file in the root directory (or rename `.env.example`):
```env
# Choose your LLM provider:
OPENAI_API_KEY=sk-proj-your_openai_key_here
# Optional if using Groq:
GROQ_API_KEY=gsk_your_groq_key_here
```

### Step 5: Generate Sample Dataset
```bash
python generate_data.py
```

## 🏃 Running the Application

### Option 1: Run Full System (FastAPI Backend + Streamlit Frontend)

1. **Start the FastAPI Backend Service:**
   ```bash
   python main.py
   ```
   *API will run at `http://localhost:8000` (Swagger docs available at `http://localhost:8000/docs`).*

2. **In a new terminal window, start Streamlit UI:**
   ```bash
   source venv/bin/activate
   streamlit run app.py
   ```
   *Dashboard will open at `http://localhost:8501`.*
